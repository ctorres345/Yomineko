# Disclaimer and responsible use

yomineko is a study tool. It reads the Japanese text inside a game you own and turns it into
word lists and flashcards. Because it works on the inside of game files, it has firm rules about
what it is for. This page states them in one place. It is not legal advice, and it does not
replace the law where you live.

## Use it on your own dumps

- Run yomineko only on a dump you made yourself from a game you own.
- yomineko reads Game Boy Advance and Game Boy Color dumps today. Any platform added later (for
  example Nintendo DS or PSP) will be one whose dumps need no keys and no decryption.
- Everything happens on your computer. Your game file is never uploaded, and yomineko has no
  telemetry and no accounts. The only network call is the dictionary download you ask for.
- What yomineko extracts from your game (the script, word lists, decks, worklists) is for your own
  study. It stays under `yomineko-out/` on your machine. Do not share it.

## What the project will not help with

The project will not add, accept or discuss:

- **Circumvention.** No breaking or bypassing of copy protection, encryption or signatures, and
  no tools or instructions for doing so.
- **Keys or decryption.** No console or game keys, in the code, the docs, an issue or a chat, and
  no support for dumps that need them.
- **Sharing ROMs.** No ROMs, saves, archives that hold them, download links or "where can I find"
  help.
- **Sharing game content.** No extracted scripts, game text, prebuilt decks or game assets, in the
  repository or anywhere the project is discussed. Profiles hold offsets, encodings and control
  codes only.
- **Cheats or ROM hacks for distribution.** yomineko rebuilds a ROM only to check that it read the
  text exactly; it is not a patching or cheating tool, and the project will not help make one.

Issues, pull requests and discussions that ask for any of these are closed without further reply.
If one includes a ROM, game text or a key, it is also deleted.
